# 🎨 Calendario de Adviento UX/UI
### 24 días de consejos para aprender sobre diseño de experiencia e interfaces

Un calendario interactivo para descubrir cada día de diciembre un consejo práctico sobre UX/UI, usabilidad, accesibilidad y diseño centrado en las personas.

---

# 🇦🇷 Español

## 🎯 Sobre el proyecto

**Calendario de Adviento UX/UI** es una aplicación web interactiva que reúne 24 recomendaciones de diseño de experiencia de usuario (UX) e interfaz de usuario (UI).

La propuesta utiliza la dinámica de un calendario de Adviento para presentar un consejo diario durante diciembre, transformando el aprendizaje de conceptos de diseño en una experiencia visual y participativa.

## 💡 Funcionalidades

- Calendario interactivo con 24 ventanas.
- Desbloqueo progresivo de consejos según el día de diciembre.
- Ventanas emergentes para visualizar cada recomendación.
- Interacciones mediante JavaScript.
- Diseño visual con temática navideña.
- Presentación de consejos sobre usabilidad, accesibilidad y diseño de interfaces.

## 🧠 Contenidos de UX/UI

Los 24 consejos incluyen conceptos fundamentales del diseño centrado en las personas:

**Experiencia de usuario (UX)**
- Diseño centrado en el usuario.
- Visibilidad del estado del sistema.
- Organización de contenidos y jerarquía visual.
- Reducción de la carga cognitiva.
- Diseño de formularios.
- Retroalimentación y gestión de errores.
- Pruebas de usabilidad con usuarios.
- Onboarding y personalización.

**Interfaz de usuario (UI)**
- Contraste y accesibilidad (WCAG 2.1 AA).
- Consistencia visual.
- Ley de Fitts y elementos interactivos.
- Microinteracciones.
- Tipografía y legibilidad.
- Diseño Mobile First.
- Iconografía y espacios en blanco.
- Botones principales y llamadas a la acción (CTA).

# 🇬🇧 English

# 🎨 UX/UI Advent Calendar
### 24 Days of Tips to Learn User Experience and Interface Design

An interactive calendar featuring one daily tip throughout December, focused on UX/UI design, usability, accessibility and user-centered design.

## 🎯 About the Project

**UX/UI Advent Calendar** is an interactive web application featuring 24 practical recommendations about User Experience (UX) and User Interface (UI) design.

Inspired by the traditional Advent calendar, it presents one design tip each day throughout December, turning the learning process into a visual and engaging experience.

## 💡 Features

- Interactive calendar with 24 windows.
- Progressive daily unlocking throughout December.
- Modal windows displaying each recommendation.
- JavaScript-based interactions.
- Christmas-themed visual design.
- Practical tips about usability, accessibility and interface design.

## 🧠 UX/UI Topics

The 24 tips cover essential user-centered design concepts:

**User Experience (UX)**
- User-centered design.
- System status visibility.
- Content organization and visual hierarchy.
- Cognitive load reduction.
- Form design.
- Feedback and error handling.
- Usability testing.
- Onboarding and personalization.

**User Interface (UI)**
- Color contrast and accessibility (WCAG 2.1 AA).
- Visual consistency.
- Fitts's Law and interactive elements.
- Microinteractions.
- Typography and readability.
- Mobile First design.
- Iconography and whitespace.
- Primary buttons and calls to action (CTA).
